Support report

After reproducing the problem, use Homey’s Create Diagnostics Report to send recent app logs directly to the developer.

Mobile: More → Apps → Frisquet Connect → settings gear → Create Diagnostics Report.

Web: Settings → Frisquet Connect → Create Diagnostics Report.

Close this configuration page to find that button. Describe what went wrong in Homey’s report form and send it. Recent anonymized responses, errors and software versions are already in the log.

Passwords, tokens, names, contacts, addresses and equipment identifiers are anonymized. Operating data such as temperatures and modes remains in the report. Nothing is sent until you choose to share it.

Homey shows its report button for App Store installations. If it is missing, or you need a longer history, use the advanced export below.

Advanced: preview or export history

Use this for a development installation, to inspect saved data, or when support requests a longer history. Previewing saves nothing to an external service.

Review this saved history before sharing it. You can attach the JSON to a support issue. It is also added to the app log for your next Homey diagnostic report.
